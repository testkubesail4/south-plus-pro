# v0.1.18

## 本版亮点

- 重做首页和版块页面，集中展示账号信息、回复提醒、速览和常用版块；子版块可从目录进入，手机、平板和桌面窗口都有对应布局。
- 支持版块图墙和分类筛选，可在列表与图墙之间切换，并按全部、精华或论坛提供的主题类型查看帖子。
- 帖子新增页码选择、首楼和最新回复等阅读入口，并记住上次阅读位置；可在“设置 → 阅读”中开启自动加载下一页。
- 图片可在全屏画廊中连续查看，支持缩放、保存、复制链接和打开原图；Android 可通过系统分享面板分享图片。
- 新增回复提醒列表，可打开对应主题或删除提醒；首页和消息入口显示未读提示。
- 新增代理设置和屏蔽配置，支持 HTTP、HTTPS、SOCKS5 代理，并可管理论坛屏蔽名单和本机的内容屏蔽规则。

## 体验优化

- 回复输入框固定在帖子底部，打开回复或引用时保留阅读位置，收起后继续保留草稿；每层帖子都提供回复、引用和更多操作。
- 发新帖默认勾选回复通知，仍可在发送前自行取消；“我的”和首页优先显示昵称与头像，登录名继续保留。
- 首页速览自动加载，等待时显示与内容布局对应的占位；版块排序、筛选和翻页操作更集中，主题标题保留论坛原有的高亮样式。
- 图片按实际显示尺寸解码，减少浏览配图时的内存占用；长图查看、鼠标滚轮和键盘操作更顺手，编辑工具栏的更多格式收进菜单。
- 屏蔽规则变化后立即更新帖子、版块列表、图墙和搜索结果，并提供撤销入口；本机规则按账号保存，论坛名单可重新同步。
- 代理可在首次设置和网络设置中配置；代理与网络优化分开使用，已保存的代理配置失效时会先提示修复或明确切回直接连接。

## 修复

- 修复图片加载完成、占位消失时位置跳动，以及大字体下小尺寸图片占位文字溢出的问题。
- 修复购买帖子后刷新内容会丢失已加载楼层，以及自动翻页时部分到底部操作没有继续加载的问题。
- 修复楼层回复发送成功后，下一次普通回复仍沿用上一层回复标题的问题。
- 修复切换账号后，旧屏蔽菜单或撤销操作可能影响新账号规则，以及部分页面未正确隐藏已屏蔽头像的问题。
- 修复网络设置保存失败时提前切换连接方式，以及配置代理后网络优化探测仍可能直接发起连接的问题。
- 修复阅读位置提示跟随到其他页面、请求等待过早结束，以及部分页面在宽窗口或深色模式下显示不一致的问题。

## 发布说明

- 本版本继续由 GitHub Actions 自动构建 Android、iOS 和 Windows 安装包。
- Release 页面提供 Android 多架构 APK、AAB、iOS sideload IPA、Windows x64 压缩包和 SHA256 校验文件。
- Android 构建号提升为 `12018`，高于 v0.1.17 所有分架构安装包的版本码。推荐按设备架构选择 APK，并使用原正式签名进行覆盖升级。
- 系统图片分享目前仅支持 Android；私信图片仅分享链接，继续保留仅使用内存缓存的处理方式。
- 本机内容屏蔽规则不会同步到论坛；帖子默认手动翻页，自动加载下一页需在设置中开启。
