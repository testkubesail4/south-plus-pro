# v0.1.22

## 本版亮点

- 新增帖内查找，可在已加载的正文、引用和代码中查找关键词，确认后逐页搜索整个主题，并打开结果对应的楼层。
- 收藏新增标题搜索，可先查找当前页面，再按需搜索当前分类或全部收藏的所有页面，并补全论坛截断的标题。
- 用户资料中的主题、回复和收藏列表新增标题查找，可结合当前版块、分类和类型等筛选条件使用；回复列表查找的是参与主题的标题。
- 首页速览支持分别配置三个栏目的来源，可保留原站默认内容，或选择指定版块的新帖、最新回复，也可隐藏不常看的栏目。
- 浏览历史支持按标题、作者和版块查找全部保留的本机记录，按今天、昨天和日期分组展示。
- 搜索页新增最近关键词，可从已有记录填入搜索框，并单独删除或清空；不同账号的记录分开保存。

## 体验优化

- 查找时明确显示已加载范围、全部页面的扫描进度和待确认数量；搜索未完成、已停止或遇到错误时保留已有结果。
- 标题不完整或筛选信息无法核实时单独列出待确认内容，避免直接当作没有匹配；全量查找可补充读取相关主题资料。
- 扫描支持停止、继续和重试，遇到网络错误或限流时提示等待；离开页面、切换账号或修改范围后停止对应扫描。
- 速览来源与显示行数集中设置，保存后更新首页；选择版块时保留父子层级，隐藏栏目时至少保留一个可见栏目。
- 最近关键词在编辑搜索框时按输入内容筛选，选择后可继续修改，再确认搜索；保存失败时保留重试入口。
- 浏览历史按需构建列表，查找时显示匹配数量；版块选择、搜索范围和待确认内容使用一致的布局，并适配深色模式、大字体与宽窗口。

## 修复

- 修复浏览历史保留了 200 条记录，但默认只读取和展示其中 100 条的问题。
- 修复用户资料中没有内容和页码的列表被提前计为已读取，以及部分分页信息不完整时仍可能被当作搜索完成的问题。
- 修复部分主题链接、作者范围和分页信息未正确核对，可能重复读取页面或使用其他范围内容的问题。
- 修复切换账号后，旧搜索记录的确认、保存结果或重试操作仍可能影响当前页面的问题。
- 修复购买后已加载范围的帖内查找仍可能使用旧内容，以及其他页面覆盖帖子后扫描没有暂停的问题。
- 修复短窗口和键盘展开时帖内查找内容无法完整滚动，以及收藏数量换行后标题和按钮未居中对齐的问题。

## 发布说明

- 本版本继续由 GitHub Actions 自动构建 Android、iOS 和 Windows 安装包。
- Release 页面提供 Android 多架构 APK、AAB、iOS sideload IPA、Windows x64 压缩包和 SHA256 校验文件。
- Android 构建号提升为 `28022`，高于此前发布的所有分架构安装包版本码。推荐按设备架构选择 APK，并使用原正式签名进行覆盖升级。
- 全量查找需要逐页访问论坛，最多保留 200 条匹配与待确认结果；耗时取决于页数和网络状态，可随时停止。收藏和资料列表按主题标题查找，帖内查找不含图片、附件和未解锁内容。
- 最近关键词和速览来源按账号保存在本机，不会同步到论坛；清除应用数据会一并清除这些设置。
