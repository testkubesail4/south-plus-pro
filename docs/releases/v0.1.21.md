# v0.1.21

## 本版亮点

- 新增原生资料编辑，可在“我的 → 编辑资料”中修改论坛提供的昵称、基本资料、生日、签名和个人介绍，并选择系统头像、头像链接或裁剪上传本机图片。
- 新增论坛偏好页面，按用途整理论坛提供的显示、日期和消息等设置；保存前重新读取表单，减少覆盖其他页面修改的情况。
- 收藏支持完整的分类管理，可新建和删除分类、移动主题或批量取消收藏；帖子收藏时可选择目标分类，确认后再显示收藏结果。
- 支持本地用户备注和标签，可在“备注与标签”中集中查看、搜索和编辑，并从对应用户进入资料页。
- 首页新增“我的版块”和版块个性化设置，可切换常用与最近访问，调整版块分区顺序或隐藏不常看的区域；版块主题列表支持连续加载。
- 用户资料中的主题和回复支持按版块、分类和帖子类型筛选，版块选择按父子层级展示，分批加载并单独提示暂时无法确认的内容。

## 体验优化

- 头像的系统图片、链接和上传选项分开显示，切换时保留对应草稿；本机图片支持方形裁剪与缩放，动图可选择保留原图。
- 生日统一为一个日期入口，按论坛提供的选项选择年、月、日，并检查日期有效性；资料页优先显示昵称，用户标识继续保留。
- 首页速览可选择每组显示 3 至 8 行，目录与子版块区域可折叠；常用版块与搜索页使用同一份列表，最近访问显示更清楚的父子版块名称。
- 收藏分类与移动操作集中在选择面板中，新建或管理分类后可继续选择目标；删除非默认分类时，其中的主题会回到默认分类。
- 标签可从已有列表复用，备注列表显示已知名称与 UID；备注或标签只保存了一部分时，会分别说明结果并保留未保存内容供重试。
- 帖子补充回复时间和个人签名等信息，付费内容购买后在原位置展开，保留已加载楼层和阅读位置；论坛任务以服务器当前返回的状态为准。

## 修复

- 修复论坛返回分类选择菜单时被误判为收藏成功，以及分类变动后仍可能使用旧编号提交的问题。
- 修复部分资料字段、头像尺寸限制和论坛偏好说明解析不准确，导致表单显示或填写受影响的问题。
- 修复切换账号或网络后，旧表单、收藏选择、备注编辑和筛选结果仍可能影响当前页面的问题。
- 修复购买已成功但刷新失败时仍可能再次购买，以及提交结果不确定时重复保存的问题；这类情况会先提示刷新核对。
- 修复常用版块、用户备注和阅读偏好保存失败后，界面状态与实际保存内容不一致的问题。
- 修复大字体下出售内容按钮、头像提示和部分表单布局不正确，以及首页版块隐藏和排序后入口显示不完整的问题。

## 发布说明

- 本版本继续由 GitHub Actions 自动构建 Android、iOS 和 Windows 安装包。
- Release 页面提供 Android 多架构 APK、AAB、iOS sideload IPA、Windows x64 压缩包和 SHA256 校验文件。
- Android 构建号提升为 `24021`，高于此前发布的所有分架构安装包版本码。推荐按设备架构选择 APK，并使用原正式签名进行覆盖升级。
- 资料、论坛偏好和收藏操作会提交到论坛，实际可用项目与头像限制以当前账号的论坛表单为准；提交结果未确认时，请先刷新核对。
- 用户备注、标签和首页阅读偏好按账号保存在本机，不会同步到论坛；清除应用数据会一并清除这些设置。
