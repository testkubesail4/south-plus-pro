# v0.1.19

## 本版亮点

- 统一首页、版块、帖子、搜索和账号页面的文字、配色与列表样式，优化深色模式、大字体和宽窗口下的显示。
- 消息入口集中展示短消息和回复提醒，可滑动切换；“我的”和设置重新整理功能分组，减少重复入口。
- 帖子重新整理首楼操作、楼层布局和翻页入口，可通过“跳转”选择页码、回到首楼或查看最新回复，并从标题栏进入所在版块或分享主题。
- 发帖、回复和私信支持统一的富文本预览，可在发送前查看文字样式、引用、表情和出售内容的显示效果。
- 收藏列表支持取消收藏，确认后向论坛提交，成功后移除对应主题；搜索结果可通过页码选择跳转到任意结果页。

## 体验优化

- 首页速览支持左右滑动切换，每组展示八条单行主题和回复数；等待加载或列表较短时保持布局稳定，并按已加载的屏蔽规则隐藏主题。
- 版块、搜索、收藏、历史和用户资料中的主题列表使用一致的行布局；论坛高亮标题以文字前的色条标记，正文颜色保持清晰。
- 帖子回复集中显示在连续列表中，作者信息、楼层和回复操作更紧凑；收藏与只看楼主集中在首楼操作区，上一篇和下一篇主题分列两侧。
- 登录页收起较少使用的选项；设置按外观、阅读、网络和关于分组，主题与文字大小可直接切换，私信详情保留回复入口，其他操作收进菜单。
- 编辑器将正文作为主要书写区域，预览、草稿和发布操作集中在顶部，格式说明从工具栏打开；用户资料、网络表单和回复输入区在宽窗口下保持适合阅读和填写的宽度。
- 加载、空列表和错误提示使用统一布局，按钮等待时保留文字并显示进度；深色模式下的按钮、页码和提示文字更容易辨认。

## 修复

- 修复大字体下正文链接被重复放大，与周围文字大小不一致的问题。
- 修复部分头像字母超出边界、表情代码换行，以及底部导航和资料标签显示不完整的问题。
- 修复深色模式下部分按钮文字、出售内容提示和加载进度对比度不足的问题。
- 修复仅因显示名称相同就给回复标记“楼主”的问题，改为按用户身份判断。
- 修复首页速览扩展加载失败时丢失已有预览，以及部分搜索结果页无法通过页码直接访问的问题。
- 修复窄屏和大字体下跳转按钮、代理类型及相邻主题操作换行后布局不正确的问题。

## 发布说明

- 本版本继续由 GitHub Actions 自动构建 Android、iOS 和 Windows 安装包。
- Release 页面提供 Android 多架构 APK、AAB、iOS sideload IPA、Windows x64 压缩包和 SHA256 校验文件。
- Android 构建号提升为 `16019`，高于 v0.1.18 所有分架构安装包的版本码。推荐按设备架构选择 APK，并使用原正式签名进行覆盖升级。
- 短消息和回复提醒统一从“消息”进入，屏蔽配置移至“我的”。
- 主题分享在 Android 使用系统分享面板，其他平台复制主题链接；编辑器预览不会发布内容。
