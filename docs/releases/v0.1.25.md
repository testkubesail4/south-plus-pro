# v0.1.25

## 本版亮点

- 新增“消息 › 关注”，可关注帖子的新增回复、用户的主题与回复、公开可见收藏，以及版块中标题匹配关键词的新主题。
- 关注规则支持关键词和涉及用户筛选，可分别暂停、编辑或删除；动态保留原生帖子与楼层入口，方便回到对应内容。
- Android 新增短消息与回复提醒系统通知，点击后进入对应列表，不自动打开私信或清除论坛提醒。
- Android 中开启通知的关注规则支持后台检查，约每 15 分钟检查一次，并通过常驻通知展示检查状态。
- 版块新增论坛原生时间范围筛选，与排序并列展示，翻页时继续保留所选范围。
- 私信列表和详情中的对方名称支持打开用户资料，用户中心新增分享入口，可分享当前站点的资料链接。

## 体验优化

- 消息、好友、任务和备注与标签等页面采用紧凑的次级标签，设置选项收进当前值菜单，减少重复说明与空状态提示。
- 设置选项支持键盘选择，返回键优先关闭已展开的菜单；主题、字号和图片加载方式在保存确认后更新，失败时保留原选择。
- 手动读取全部页面不再在 200 条结果处提前结束，继续支持确认、停止与重试，并沿用论坛分页和请求节奏。
- 阅读私信后返回时保留原列表、已加载页面和滚动位置，已读状态在原位置更新；删除等操作后按论坛结果刷新。
- 仅包含主题地址的回复提醒可打开主题末页，原链接带有页码或楼层时继续保留对应位置。
- 同轮关注检查合并系统通知，短消息与回复提醒分别保留摘要；通知不展示论坛标题、作者或消息正文。

## 修复

- 修复私信重读先后返回时，旧结果可能覆盖新状态，以及已丢弃的追加页面可能重新出现的问题。
- 修复回复提交期间切换账号或站点后，旧操作可能继续使用新会话发送的问题。
- 修复关注数据读取失败后无法恢复、误显示为没有关注，并影响其他通知检查的问题；读取失败保留明确提示与重试入口。
- 修复 iOS 拒绝通知权限后，“去设置”无法打开系统设置的问题，并在返回应用时重新检查权限。
- 修复消息页被其他页面或弹窗覆盖时，关注通知无法正常进入动态列表的问题；遇到未保存的编辑时先确认是否放弃。
- 修复暂停关注的保存尚未完成时切到后台，保存失败回滚后未恢复轮询的问题；恢复检查不会推迟已有定时器或预算续跑时间。

## 发布说明

- 本版本继续由 GitHub Actions 自动构建 Android、iOS 和 Windows 安装包。
- Release 页面提供 Android 多架构 APK、AAB、iOS sideload IPA、Windows x64 压缩包和 SHA256 校验文件。
- Android 构建号提升为 `40025`，高于此前发布的所有分架构安装包版本码。推荐按设备架构选择 APK，并使用原正式签名进行覆盖升级。
- 关注规则和动态按账号保存在本机，首次检查只建立可见快照，不补发历史动态；最多启用 10 条、保存 30 条规则。
- Android 后台检查需要通知权限和开启通知的有效关注规则，系统可能延迟或停止检查，关闭应用后不再检查；iOS 仅在使用应用时检查，Windows 保留应用内动态。
- 关注只能判断论坛当前可见的内容；新可见收藏不代表收藏操作时间，涉及用户的引用文字匹配仅供参考，不发送系统通知。
