# v0.1.28

## 本版亮点

- 修复从旧版覆盖升级后，“我的”仍显示已登录，打开茶馆等版块的帖子却提示“注册会员才能查看”的问题。
- 帖子里的动图默认显示首帧，点开查看器后播放原图。在“设置 › 阅读 › 帖子动图”中可选“正文静止时播放”，滚动时暂停，停稳后恢复。

## 体验优化

- 同一楼层有多张图片时，滚动到图片附近再加载。正文按显示尺寸解码 GIF 首帧，减少多图长帖的内存占用和滚动卡顿。
- 启动应用和首次切换到保存的账号时会核对登录状态。已失效的账号在账号列表中显示“需重新登录”，其他账号可继续使用。断网或请求超时时保留原有会话。

## 修复

- 修复验证码键盘的完成键和“登录”按钮同时触发时，可能重复提交登录请求的问题。
- 修复部分 GIF 被图片服务器标记为 PNG 时无法正常播放，以及断开 Wi-Fi 后“仅 Wi-Fi 自动加载”仍可能继续加载图片的问题。
- 修复宽屏版块列表和发帖页“新回复站内通知”的点击反馈被背景遮住的问题，修正搜索全部页面时读屏获取的进度值。

## 发布说明

- 已安装 v0.1.26 或已撤回的 v0.1.27 的用户可直接覆盖升级。如果账号显示“需重新登录”，从账号列表重新登录即可，无需清除应用数据。
- Android 构建号提升为 `52028`，高于 v0.1.27 的所有分架构安装包版本码。Android、iOS 和 Windows 正式包统一使用与 v0.1.26 相同的 Flutter `3.47.9` 构建。
