# v0.1.16

## 本版亮点

- 已购买的出售帖会完整显示解锁后的正文和下载链接，0 SP 内容也能正常阅读。
- 新增无图模式，可在“我的 → 图片与流量”中切换。论坛图片、头像、表情和预览截图会隐藏，文字、链接和附件操作继续保留。
- Android 附件下载使用 App 当前的登录状态，不需要跳到外部浏览器重新登录。Android 10 及以上会保存到系统下载目录的 `SouthPlus` 文件夹。
- Android 检查更新会按设备架构选择安装包，减少因下载错误架构版本而被系统判断为降级的问题。

## 体验优化

- 无图模式会保存设置，重新启动后继续生效；切回自动加载后，图片和头像会恢复显示。
- 附件的小图标保持原有尺寸，正常图片按可用空间等比例显示，避免小图标被放大成模糊的大图。
- 附件下载提供进度、完成和失败反馈，并避免重复点击同时发起保存；返回上一页后，下载进度提示也会正确结束。
- 日常、周常的完成状态和重复领取提示更准确，任务奖励到账后会回到已完成列表。

## 修复

- 修复出售内容解锁后，售价提示下方的正文和下载链接被忽略的问题。
- 修复部分论坛任务响应被错误解析，导致奖励已领取却仍停在“进行中”的问题。
- 修复任务奖励数量和已完成状态报告不准确的问题。
- 修复附件链接交给未登录的外部浏览器后，被论坛拒绝下载的问题。
- 修复附件图标被按大图布局放大，以及下载进度在页面退出后残留的问题。
- 修复 Android 更新优先选择 universal 包，可能导致覆盖安装被判断为降级的问题。

## 发布说明

- 本版本继续由 GitHub Actions 自动构建 Android、iOS 和 Windows 安装包。
- Release 页面提供 Android 多架构 APK、AAB、iOS sideload IPA、Windows x64 压缩包和 SHA256 校验文件。
- Android 构建号提升为 `4016`，高于此前发布的分架构安装包版本码。推荐按设备架构选择 APK，并使用原正式签名进行覆盖升级。
- 原生附件保存目前仅支持 Android；Android 7–9 使用系统文件保存器，Android 10 及以上使用系统下载目录。
