# v0.1.26

## 本版亮点

- 新增多账号管理，可添加、切换、重新登录、退出当前账号或移除账号。
- 登录会话、浏览历史、阅读位置和屏蔽设置按站点与账号隔离，切换账号时撤下原账号的页面内容。
- 应用在前台时定时检查消息并更新首页内容；下拉刷新首页时同时同步消息，收到新短消息或回复提醒时显示应用内横幅，点击进入对应列表。
- 针对带有“回 N楼(作者) 的帖子”标题的回复，在正文前展示被回复楼层与作者，点击可查找并定位对应楼层。
- 首页版块设置可分别隐藏热门版块和最近访问，“我的”页面新增“我的收藏”入口。

## 体验优化

- 版块记住所选排序和列表或图墙视图，作为之后打开版块的默认值；图墙仅在论坛提供相应内容的版块展示。
- 首页布局和版块视图偏好按站点与账号保存在本机，隐藏最近访问时保留访问记录。
- 消息列表接收前台同步结果，保留当前阅读内容；首页静默刷新失败时保留已有内容，下拉刷新时消息同步失败可重试。
- 统一加载、空状态和分页末尾的展示，减少重复说明；关注页保留下拉刷新和可用鼠标、键盘操作的“立即检查”按钮，仅在规则已暂停或检查失败时展示状态。

## 修复

- 修复正常页面中的正文、签名或用户内容包含限流提示文字时，可能被误判为“请求过于频繁”的问题。
- 修复私信读取、聊天记录读取或私信操作后，较早发起的收件箱请求可能覆盖新状态或重新写回旧缓存的问题。
- 修复快速切换消息入口时，短消息与回复提醒的目标可能错位，以及同步结果返回后刷新状态未及时更新的问题。
- 修复切换账号、站点或离开登录页后，较晚返回的登录结果可能更新当前会话或页面的问题。
- 修复楼层顶部的编辑入口可能被误当成个人签名的问题。

## 发布说明

- 本版本继续由 GitHub Actions 自动构建 Android、iOS 和 Windows 安装包。
- Release 页面提供 Android 多架构 APK、AAB、iOS sideload IPA、Windows x64 压缩包和 SHA256 校验文件。
- Android 构建号提升为 `44026`，高于此前发布的所有分架构安装包版本码。推荐按设备架构选择 APK，并使用原正式签名进行覆盖升级。
- 前台消息同步沿用论坛请求间隔与请求预算，实际更新受网络和论坛限制影响；Android 后台关注检查仍受系统调度约束。
- 楼层查找每次最多读取 20 个尚未加载的页面，超过上限时提示手动切换页面后重试；仅定位当前可见的楼层，未找到目标楼层时保留当前页面并提示。
