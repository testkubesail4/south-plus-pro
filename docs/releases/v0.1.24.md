# v0.1.24

## 本版亮点

- 新增好友管理，可添加好友、填写验证申请、接受或拒绝申请，并在好友列表中删除好友。
- 自己的用户资料支持展示好友的最近活动，主题和回复可直接打开，成为好友的动态可进入对应用户资料。
- 论坛链接支持在应用内打开版块、用户资料、消息、好友、任务和个人设置等页面，保留原链接中的分页与消息范围。
- 网络设置重新整理为直接连接、网络优化和代理三种模式，站点入口可独立选择，并提供连接测试和取消入口。
- 网络优化支持加密 DNS、自定义解析服务和按站点配置的备用地址，可按需开启 IPv6；首次使用引导可在离线状态下完成配置。
- 新增“加载与分页”设置，帖子、版块、搜索、收藏、用户内容、消息、好友和头像列表可分别选择手动翻页或连续加载。

## 体验优化

- 连续加载沿用论坛提供的下一页地址，合并重复内容；读取失败或没有新增内容时暂停，并保留重试入口。
- 帖内查找、用户内容排序等需要读取全部页面的操作继续先行确认，翻页方式可按自己的阅读习惯分别保存。
- 统一主要页面的标题与切换动效，加载状态和同级页面切换更加连贯；开启系统减少动态效果后减少位移和滚动动画。
- 优化窄窗口、大字号和验证码输入体验，刷新验证码时保留当前文字输入焦点。
- 切换网络配置时统一更新连接与图片请求；仅调整同一站点的连接模式时保留当前账号会话。
- 好友操作展示论坛返回的申请与处理结果；结果无法确认时提示先到论坛核实，避免重复发送。

## 修复

- 修复个人消息与群发消息使用相同编号时，其中一条可能被错误合并而不显示的问题。
- 修复桌面端快速切换收件箱与发件箱时，滚动条可能异常或无法正常拖动的问题。
- 修复切换账号或站点后，部分页面、消息列表和弹出内容仍可能保留旧会话私密信息的问题。
- 修复保存网络配置时，首页内嵌消息列表可能影响设置页面返回，以及独立打开的收件箱未及时撤下旧内容的问题。
- 修复部分论坛链接未保留原始消息类型、分页和资料入口，以及不支持的操作链接未明确转交浏览器的问题。
- 修复旧请求返回时可能影响新账号、新站点或新网络配置的问题，完善凭据隔离和退出后的状态清理。

## 发布说明

- 本版本继续由 GitHub Actions 自动构建 Android、iOS 和 Windows 安装包。
- Release 页面提供 Android 多架构 APK、AAB、iOS sideload IPA、Windows x64 压缩包和 SHA256 校验文件。
- Android 构建号提升为 `36024`，高于此前发布的所有分架构安装包版本码。推荐按设备架构选择 APK，并使用原正式签名进行覆盖升级。
- 好友申请、处理和删除以论坛实际提供的权限与结果为准；结果未确认时请先到论坛核实，不要重复操作。
- 升级时保留原有站点与代理设置，旧版未区分站点的备用地址不再沿用；代理模式不会在连接失败后自动改为直接连接，外部浏览器和系统下载不使用应用内网络配置。
- 加载与分页设置保存在本机，清除应用数据会一并清除；连续加载会继续访问论坛，耗时和流量取决于内容数量与网络状态。
