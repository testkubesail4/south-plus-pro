# v0.1.17

## 本版亮点

- 新增站内私信，可查看收件箱、发件箱和消息跟踪，阅读、发送和回复消息，并按论坛提供的权限执行相关操作。
- 重做高级搜索，支持关键词、按用户查找、版块范围和更多论坛搜索条件；搜索偏好与常用版块按账号保存，结果按论坛分页展示。
- 帖子和私信使用统一的原生富文本显示，支持引用、代码、列表、文字样式、图片和论坛表情；发帖、回复和私信编辑器提供格式与表情工具栏。
- 底部导航调整为“首页、收藏、搜索、消息、我的”，账号内容与设备设置分开，常用功能更容易找到。
- Android 可接收其他应用打开的论坛链接，将主题、用户和版块链接带到对应的应用内页面；搜索链接会预填条件，确认后再搜索。

## 体验优化

- 版块列表支持论坛提供的四种排序方式，刷新和翻页时保留当前排序。
- 新增可保存的文字大小设置，并继续尊重系统字体缩放；发新帖时可自行选择是否接收论坛回复通知。
- 论坛镜像链接可跳转到对应的原生页面，主题支持定位楼层和“只看楼主”，减少阅读过程中的来回查找。
- 搜索版块选择器按首页层级折叠展示；用户资料页可查看登录名并预填“按人查找”，避免把显示名称误当成登录名。
- 用户资料和收藏页减少无关请求，资料短时复用，降低重复打开页面时的等待；网络错误和搜索冷却提示更明确。
- 私信图片仅使用内存缓存；退出详情后清理相关缓存，减少私人内容在设备上的留存。

## 修复

- 修复连接或 TLS 握手失败时没有继续尝试下一个可用地址的问题。
- 修复部分搜索失败被显示为空结果、切换账号后仍显示旧搜索结果，以及用户不存在与无匹配结果提示混淆的问题。
- 修复链接、表情和图片之间的换行丢失，以及代码块混入论坛表格和“复制代码”装饰的问题。
- 修复从链接进入版块时名称显示不准确、部分帖子标题被误判为错误页面的问题。
- 修复编辑工具栏超出屏幕、图片查看比例不正确和超长图片占用过多内存的问题。
- 修复 Android 页面切换时闪白，以及登录返回、退出账号和账号切换时部分页面状态不正确的问题。

## 发布说明

- 本版本继续由 GitHub Actions 自动构建 Android、iOS 和 Windows 安装包。
- Release 页面提供 Android 多架构 APK、AAB、iOS sideload IPA、Windows x64 压缩包和 SHA256 校验文件。
- Android 构建号提升为 `8017`，高于 v0.1.16 所有分架构安装包的版本码。推荐按设备架构选择 APK，并使用原正式签名进行覆盖升级。
- 从其他应用接收论坛链接目前仅支持 Android，是否交给本应用打开取决于系统与来源应用的链接处理方式。
