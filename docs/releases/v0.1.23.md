# v0.1.23

## 本版亮点

- 新增帖子编辑，可从论坛允许编辑的主题和楼层菜单进入，读取原始正文，预览后保存，并在失败时保留已修改的内容。
- 发帖支持读取版块原生分类和悬赏规则，可填写最佳答案与热心助人金额，确认预扣金额后发布悬赏帖。
- 悬赏帖支持给出热心助人和选择最佳答案，操作前显示金额与规则；帖子内可查看悬赏状态、获奖楼层和最近评分。
- 用户标签支持自选颜色，同一账号下的同名标签使用相同颜色，可在备注编辑器和标签管理中修改。
- 用户资料将首页与资料合并为概览，基本信息先展示，最近活动单独加载；主题和回复列表新增排序入口。
- 浏览历史新增年、月、日筛选，可与标题、作者和版块查找组合使用，并一键清除日期条件。

## 体验优化

- 资料中的主题列表支持按时间、浏览量和回复量排序，回复列表按自己的回复时间排序；缺少数据的内容始终排在最后。
- 排序明确区分已加载范围与全部页面，读取全部页面前先确认；版块、类型和分类筛选集中收起，启用的条件保留在列表上方。
- 帖内查找明确区分“仅已加载”和“全部页面”，仅已加载模式不额外访问论坛，全部页面模式继续支持确认、停止和重试。
- 主题翻到第二页及以后时，楼主简要信息保留发帖时间和签名，方便对照正文；图片仍留在原楼层展示。
- 编辑页面在短窗口和键盘展开时可以完整滚动，保存结果显示在输入区域上方；用户资料头像可直接打开大图。
- 悬赏操作展示扣费、押金退回和结束条件；发布或奖励结果无法确认时提示先到论坛核实，并阻止重复发送。

## 修复

- 修复点击“从头看”后重新进入主题，仍可能恢复到旧楼层的问题。
- 修复部分带外层容器的主题正文未正确关联楼主锚点，导致跳转和阅读位置记录不准确的问题。
- 修复用户资料中某个列表返回不完整时，其他已加载列表也受到影响的问题；出错的列表单独显示提示和重试入口。
- 修复编辑时可能使用展示后的正文代替原始内容，导致链接、表情和部分论坛表单字段丢失的问题。
- 修复部分原生操作未充分核对帖子、账号和会话范围，以及仅凭不明确的论坛响应判断操作成功的问题。
- 修复草稿写入返回失败时仍提示已保存的问题；保存失败会保留编辑内容并提示复制或重试，已确认发布的主题不受本地草稿清理失败影响。

## 发布说明

- 本版本继续由 GitHub Actions 自动构建 Android、iOS 和 Windows 安装包。
- Release 页面提供 Android 多架构 APK、AAB、iOS sideload IPA、Windows x64 压缩包和 SHA256 校验文件。
- Android 构建号提升为 `32023`，高于此前发布的所有分架构安装包版本码。推荐按设备架构选择 APK，并使用原正式签名进行覆盖升级。
- 编辑、悬赏发帖和奖励入口以论坛实际提供的权限与规则为准；选择最佳答案会结束悬赏，无法撤销或改选。结果未确认时请先到版块核实，不要重复发布或奖励。
- 全部页面排序需要逐页访问论坛，耗时取决于页数和网络状态；浏览历史的日期筛选仅作用于本机保留的记录。
- 标签颜色按账号保存在本机，不会同步到论坛；清除应用数据会一并清除这些设置。
